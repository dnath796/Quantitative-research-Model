derivatives-pricing-engine

A four-language (Python / C++ / Rust / Java) pricing library for vanilla and first-generation exotic options: analytic Black-Scholes-Merton and Garman-Kohlhagen with the full Greek set and a bracketed-Newton implied-vol solver, CRR and Jarrow-Rudd binomial trees with American exercise, and an exact-step GBM Monte Carlo engine for Europeans, Asians, barriers and lookbacks. The Python package is the reference; the three ports implement the contract pinned normatively in API_SPEC.md, and all four consume one 28-case golden file stored at full double precision.

What the latest review changed. The review found that binomial_greeks with the smallest legal tree (steps = 2) crashed in Python (IndexError) and Java (NPE) and read out of bounds in C++ (undefined behaviour) because the terminal level was not stored; and that implied_vol, when max_iter ran out, fell off the end of its loop and returned a half-converged root as if it had converged. Both were fixed in all four ports — the solver now raises a non-convergence error naming the residual and final bracket, validates tol > 0 and max_iter ≥ 1, and caps the bracket at exactly 20.0. The same pass pinned the seed and rel_bump domains, added the lattice overflow guard, replaced C++'s implementation-defined std::normal_distribution with a fixed Box-Muller recipe, and regenerated the goldens at full double precision with three new single-step barrier/lookback anchor cases (28 total). Remaining by design: barrier and lookback are the discretely monitored contracts with O(1/√n_steps) bias and no Broadie–Glasserman–Kou correction; MC streams are deterministic per language but differ across languages.

What's inside

Analytic BSM & Garman-Kohlhagen

Black-Scholes-Merton with continuous dividend yield q and Garman-Kohlhagen FX pricing with r = rd, q = rf. Prices plus delta, gamma, vega, theta, rho, vanna and volga; exact branches for t = 0, σ = 0 and k = 0 return the analytic limits with second-order Greeks exactly zero instead of platform-dependent NaNs.

Implied volatility

Refuses prices at or outside the no-arbitrage interval before iterating (a deep-ITM price sitting exactly at discounted intrinsic is rejected, not returned as σ = 0), then runs safeguarded Newton (Numerical Recipes rtsafe style) with bisection fallback. Round-trips σ → price → σ to 1e-6 for σ in [0.05, 0.8]; vols up to the cap (1.7, 17.0) round-trip through bracket expansion.

Binomial trees

Cox-Ross-Rubinstein and Jarrow-Rudd lattices with European and American exercise, tree Greeks (delta, gamma, theta) requiring steps ≥ 2, and optional two-point odd/even Richardson averaging. Raises when the risk-neutral probability leaves (0, 1) at the chosen step size. Put-call parity holds exactly on the CRR lattice and is tested that way.

Monte Carlo

Exact-step GBM (no Euler bias in marginals) pricing European vanillas, arithmetic Asians with a geometric-Asian control variate, discretely monitored up-and-out barriers and floating-strike lookbacks; antithetic and control variates with honest standard errors (pair averages, in-sample β) and 95% confidence intervals. C++ and Rust stream paths in O(n_steps) memory; Python and Java materialise the path matrix.

Monte Carlo deltas

Pathwise delta (Broadie–Glasserman) and finite-difference delta with common random numbers, each with its own standard error; in the demo (100k paths) both land within two SE of the analytic 0.6368. Digital and other discontinuous payoffs are out of scope for the pathwise estimator.

FX helpers & realised vol

Forward, spot ⇄ forward delta conversion (premium-excluded spot delta per Wystup's conventions), and historical volatility from a close series with a configurable periods_per_year. No premium-included deltas, foreign rho or strike-from-delta solver.

Golden-value testing

Every suite parses the same flat JSON (C++ with a hand-rolled reader, Rust with serde_json, Java with a bundled parser), asserts each case within its absolute tol, and fails on a case name it cannot dispatch — a new case breaks all four builds until all four implement it. No suite pins the exact count (all assert ≥ 20).

Property, limit and error tests

Per language: put-call parity over an (s, k, t) grid; Greeks against central finite differences; monotonicity in s and k; American ≥ European and the dividend-driven early-exercise premium of a call; barrier ≤ vanilla, Asian ≤ vanilla; the one-step CRR closed form; the single-fixing Asian bit-identical to the vanilla engine; the σ = 0 MC limit; every invalid input raising with the documented message.

Reference papers

Black & Scholes (1973), Merton (1973), Garman & Kohlhagen (1983) for the analytic engines; Cox, Ross & Rubinstein (1979) and Jarrow & Rudd (1983) for the lattices; Kemna & Vorst (1990) for the geometric-Asian control; Broadie & Glasserman (1996) for the pathwise delta; Glasserman (2004); Broadie, Glasserman & Kou (1997) documented, not applied; Cody (1969, 1993) for erfc; Haug (2007), Hull (2022), Wystup (2006).

Units and what is out of scope

t is a year fraction (no day-count or calendar work); σ, r, q are decimals with continuous compounding; theta is per calendar year, vega/vanna/volga per unit of vol, rho per unit of rate. Not covered: discrete cash dividends, term structures of rates or vol, American exercise outside the lattice, market-data or persistence layers — a verified reference implementation of textbook models, not a risk system.

Quick start

git clone https://github.com/AshJha0/derivatives-pricing-engine.git
cd derivatives-pricing-engine

# Python (3.11+, numpy + pandas; pytest for tests)
cd python
pip install -r requirements.txt
PYTHONPATH=src python3 -m pytest -q  # 81 functions / 150 collected cases
PYTHONPATH=src python3 demo.py       # end-to-end demo
cd ..

# C++ (C++17, CMake >= 3.16, GoogleTest)
cd cpp
bash build.sh                                 # cmake configure + build (Release, -j2)
ctest --test-dir build --output-on-failure    # 61 tests
./build/demo
cd ..

# Rust (1.95, edition 2021)
cd rust
cargo build --release
cargo test --release                 # 46 tests + 1 doctest, incl. golden
cargo run --release --bin demo
cd ..

# Java (21; JUnit 4 + Hamcrest, no Maven/Gradle)
cd java
bash build.sh    # javac -Xlint:all -Werror into out/
bash test.sh     # 54 tests
bash demo.sh
